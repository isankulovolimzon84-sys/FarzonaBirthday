FARZONA BIRTHDAY — Android loyiha

APK yaratish:
1. Loyihani GitHub'da yangi repositoryga yuklang.
2. Actions bo‘limiga kiring.
3. "Build Farzona Birthday APK" workflow'ini tanlang.
4. Run workflow tugmasini bosing.
5. Build tugagach, Artifacts ichidan FarzonaBirthday-APK ni yuklab oling.
6. ZIP ichidagi app-debug.apk faylini Android telefonga o‘rnating.

Eslatma: Bu birinchi ishlaydigan boshlang‘ich versiya. Hozircha fon musiqasi qo‘shilmagan; keyingi bosqichda o‘zingiz tanlagan musiqa qo‘shishimiz mumkin.
